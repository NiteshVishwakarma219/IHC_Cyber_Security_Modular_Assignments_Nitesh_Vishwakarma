DESIGN RATIONALE

Useful warnings, not more noise.

LinkCheck demonstrates a just-in-time security nudge: the user sees a concise warning when simple URL signals warrant a pause, with a plain-language explanation and a clear way to go back.

Timely

The warning appears when the user submits a link for review, close to the decision to open it.

Actionable

Each warning identifies a reason and suggests checking the domain or source independently.

Respectful

The design avoids shaming the user and preserves a deliberate choice instead of using manipulative language.

Honest

The prototype clearly states that its heuristic is not a reputation service and can miss malicious links or flag benign ones.

Evaluation note: This is a prototype and reasoned heuristic evaluation, not a completed user study. Do not report user feedback unless you actually collect it.
